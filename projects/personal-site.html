个人网站

2026.10 至今 · 个人项目 · 设计 + 开发 · 源码

问题

需要一个能长期维护的公开主页：放简历、项目和文章。约束是没有服务器预算、要能随时改、还要足够快——打开一个简历页不应该等三秒。

方案

  • 纯静态 HTML + 一个 CSS 文件，不引入构建工具，改完保存就是结果
  • 目录即路由：/projects/、/blog/ 下各放一个 index.html，URL 里不带 .html
  • GitHub Pages 托管，HTTPS 自动签发，推送即发布
  • CSS 自定义属性管理配色，深浅色跟随系统切换

为什么不用框架

内容量小的时候，构建链路的维护成本高于它带来的收益：不用装依赖、不用等编译、不用担心某天升级后构建失败。反过来，手写的静态页面本身就是"前端能力"的一部分展示——它足够快，也足够好读。

难点

  1. 打印样式：简历需要能一键导出 PDF，得单独处理分页、颜色和链接显示，否则打印出来是一堆深色背景。
  2. 路径切换：从单页扩展成多页时，所有相对路径都要改成以 / 开头的绝对路径，否则子目录下的页面会引用不到样式。
  3. Jekyll 默认处理：GitHub Pages 会自动跑 Jekyll，下划线开头的文件会被忽略，加一个空的 .nojekyll 关闭它。

结果

  • 0 个 JS 文件，1 个 CSS 文件（约 6 KB）
  • 新增一个页面只需要新建目录和 index.html
  • 部署流程：git push，约一分钟上线

复盘

如果文章超过 30 篇，会换成 Astro：用 Markdown 写，自动生成列表、标签和 RSS，比手写 HTML 更可持续。另外，sitemap 和 RSS 应该在第一版就加上，而不是等到内容多了再补。
